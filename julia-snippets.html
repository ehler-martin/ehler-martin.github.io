How execution works

Opening this page starts Julia on Binder. The environment includes Primes, Plots, LinearAlgebra, Combinatorics, and Symbolics. You can click Execute while it starts. Boxes run in the order you click them. After editing a definition, execute it again, then rerun any box whose output you want to update. Reloading the page starts fresh. An internet connection is required.
